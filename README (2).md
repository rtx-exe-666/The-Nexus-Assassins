## What is VidyaBot?
VidyaBot is a 24/7 AI-powered study assistant for Indian students (AKTU, CBSE, JEE, NEET). It answers doubts, explains concepts, gives practice questions, and provides exam tips — in Hindi or English.

## Features
- 6 subjects: Maths, Physics, Chemistry, CS, English, GK
- Hindi + English support
- Practice question generator
- Exam tips
- Works on mobile and desktop

## Tech Stack
- HTML + CSS + JavaScript (Frontend)
- Anthropic Claude API (AI Brain)
- GitHub Pages (Hosting)

## How to Run

### Step 1 — Get your API Key
- Go to console.anthropic.com
- Create an account and get your API key

### Step 2 — Add API Key
- Open `index.html`
- Find this line: `const API_KEY = 'YOUR_ANTHROPIC_API_KEY_HERE';`
- Replace with your actual key

### Step 3 — Deploy on GitHub Pages
1. Create a new GitHub repo named `vidyabot`
2. Upload `index.html` and `README.md`
3. Go to Settings → Pages → Source: main branch
4. Your site will be live at: `https://yourusername.github.io/vidyabot`
